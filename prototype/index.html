    Ma progression
    
    
    Importe tes fichiers de stats Kovaak's. Jade les lit directement sur ton navigateur, rien n'est envoyé ailleurs.
    
  
    
  
    
    
    
      
    
      
    Dépose tes fichiers de stats
    
      
    Glisse les fichiers CSV ici, ou sélectionne directement le dossier stats.
    
      
    
        
        
      
    
      
      
      
    
        ...\steamapps\common\FPSAimTrainer\FPSAimTrainer\stats
        
      
    
    
    
    
    
      
    Où trouver le dossier
    
      
      
        
    1. Ouvre Steam, clic droit sur Kovaak's, Gérer, Parcourir les fichiers locaux.
      2. 
        
    2. Entre dans le dossier FPSAimTrainer, puis stats.
      3. 
        
    3. Glisse les fichiers ici, ou utilise le bouton de sélection du dossier.
      4. 
      
    
      
    Un site web n'a pas le droit d'ouvrir un dossier tout seul sur ton PC, c'est une sécurité du navigateur. L'application Jade, elle, pourra surveiller ce dossier et envoyer tes séances automatiquement.
